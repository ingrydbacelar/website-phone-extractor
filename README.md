## Sobre o projeto

O **Website Phone Extractor** foi desenvolvido para facilitar a identificação e extração de **números de telefone disponíveis em sites de empresas**, automatizando uma tarefa que normalmente seria realizada de forma manual.

## Funcionalidades

* Extração de números de telefone de websites
* Processamento de URLs
* Identificação de diferentes números disponíveis nas páginas
* Processamento automatizado das informações
* Organização dos resultados
* Interface web intuitiva

## Tecnologias

* Python
* FastAPI
* JavaScript
* HTML5
* CSS3
